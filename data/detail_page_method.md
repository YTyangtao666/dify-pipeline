AI做电商详情页不是做几张海报！而是一套"视觉逼单"

从产品信息到购买决策：一份可复用的 AI 电商详情页方法论与 10 个行业案例库

一句话定义：详情页不是把卖点做成八张好看的图，而是按买家的决策顺序，逐屏消除"不下单"的理由。
核心公式：用户疑问 → 页面任务 → 产品卖点 → 视觉证据 → 购买理由。

# 01｜先搞明白：详情页到底在做什么
一套详情页是一条纵向销售路径：它要让用户从"看见产品"逐步走到"相信、适合、愿意购买"。卖点不是页面的起点；用户的顾虑才是。
真正的转化逻辑：不是硬推用户"立刻购买"，而是连续回答用户心里的问题。每回答一个关键问题，就少一个离开的理由。

# 02｜为什么常见 8 屏，但绝不是必须 8 屏
| 产品决策复杂度 | 建议屏数 | 适用场景 |
|---|---|---|
| 低决策、低客单 | 4—6 屏 | 信息少、购买快；用更少屏幕完成定位、证明和收口。 |
| 常规消费品 | 6—10 屏 | 服饰、快消、家居、个护、小家电；8 屏通常是最容易覆盖完整路径的起点。 |
| 高客单或复杂产品 | 10—16 屏 | 数码、大家电、母婴、安全类、专业设备；需要更多证据、对比、参数和售后说明。 |

增减页面唯一标准：每增加一屏，是否解决了一个此前没有被回答的购买问题？如果只是换背景重复同一卖点，就应该合并。

# 03｜最通用的 8 屏"视觉逼单"结构
| 屏 | 用户问题 | 页面任务 | 有效视觉证据 |
|---|---|---|---|
| 01 首屏定位 | 这是什么？适合我吗？ | 一秒建立品类、对象和最大价值。 | 产品主视觉 + 对的人/场景。 |
| 02 真实痛点 | 我真的有这个问题吗？ | 让用户代入原来的麻烦。 | 真实使用场景、问题局部、旧方案的不便。 |
| 03 核心方案 | 它怎么解决？ | 尽早给出最强购买理由。 | 功能可视化、结构、食材、效果过程、对比。 |
| 04 场景代入 | 适合我的生活吗？ | 扩大产品的真实使用价值。 | 高频情境、人物动作、使用时刻。 |
| 05 细节证明 | 为什么它真的好用？ | 通过结构、材质、设计建立可信度。 | 超微距、拆解、局部标注、工艺镜头。 |
| 06 使用门槛 | 用起来麻烦吗？ | 降低学习成本和行动阻力。 | 连续动作、手部演示、S 形流程、真实操作。 |
| 07 类目化信任 | 我最后还担心什么？ | 回答该品类无伤大雅的"风险"，让用户觉得自己在理性决策。 | 尺码选择、风味地图、清洗结构、开箱体验、储存说明等。 |
| 08 决策收口 | 为什么最终选择它？ | 让用户记住并带走 3—4 个购买理由。 | 最终产品英雄图 + 已被证明过的卖点收束。 |

# 04｜AI 详情页的 8 个设计原则
1. 先排用户决策，再排产品卖点。先问"这一屏要消除什么顾虑"，再问"放哪个卖点"。
2. 一屏一个主结论。可以有辅助信息，但只能有一个最希望用户记住的结论。
3. 参数必须翻译成用户利益。功能不是终点；用户要知道它会带来什么体验、节省什么麻烦。
4. 结论必须有视觉证据。功能用过程或对比证明；质感用微距证明；场景用人物和环境证明。
5. 人物不是装饰，纯产品也不能缺席。人物承担代入、痛点和使用证明；纯产品页承担功能、细节与信任。两者交替才有节奏。
6. 每个类目的第 7 屏都不同。吸尘器讲清洗结构、服装讲尺码、猫粮讲配料与储存、饮料讲风味、纸尿裤讲尺码选择。
7. 构图由页面任务决定，不套三分屏模板。相邻两页不使用同一种构图，避免整套图像 PPT。
8. AI 先控一致性，再追求创意。产品外观、包装、人物、Logo、颜色和物理逻辑必须锁定；文字和真实信息必须人工复核。

# 05｜从 0 到 1 的 AI 详情页工作流
| 步骤 | 要做什么 | 交付物 |
|---|---|---|
| 1. 建产品主档 | 锁定品类、价格带、目标人群、外观、结构、颜色、包装、真实参数和不能改的事实。 | 产品不可变信息表。 |
| 2. 列购买疑虑 | 从"是否需要、是否有效、是否适合、是否可信、是否方便、是否值得"列出问题并排序。 | 用户疑虑清单。 |
| 3. 做卖点—利益—证据表 | 把每个卖点翻译为用户利益，并规定必须出现的事实与视觉证据。 | 证据映射表。 |
| 4. 分配页面任务 | 给每一屏写清：用户问题、主结论、画面任务、产品角度、文案位置、禁止重复点。 | 八屏任务表。 |
| 5. 先画低保真线框 | 确认阅读顺序、产品比例、标题区、场景区和留白；此时不追求精美。 | 八屏缩略线框。 |
| 6. 建视觉与品牌系统 | 确定主色、辅助色、字体层级、Logo、包装、光线、图标、人物和镜头语言。 | 视觉规范 + 产品锚点。 |
| 7. 生成分屏视觉 | 先出首屏作为产品与人物参考，再逐屏生成；每页明确构图、镜头、文字和负面约束。 | 8 张单屏成品。 |
| 8. 后期排版与真实信息核验 | 检查中文、尺寸、参数、认证、包装清单、色差、结构、人物手部和物理逻辑。 | 可上架详情页。 |
| 9. 整套质量检查 | 从销售逻辑、产品一致性、手机端可读性、视觉节奏和合规信息五方面审查。 | 质检清单。 |
| 10. 用数据迭代 | 根据流失、咨询、评论和退货原因，前移关键卖点、补证据或删除重复页。 | 下一版优化假设。 |

# 06｜可复用的提示词生产系统
每套提示词必须先锁定：
- 产品锚点：颜色、形状、结构、配件、Logo、包装。
- 人物锚点：人物身份、服装、发型、宠物或家庭关系。
- 品牌锚点：品牌名、产品名、包装信息层级与主视觉符号。
- 视觉锚点：色彩、光线、材质、镜头语言、文字风格。

每一屏提示词必须写清：
- 这一屏回答的用户问题与唯一主结论。
- 产品 / 人物是否出现，谁是画面主角。
- 构图、镜头、前中后景、文案位置。
- 必须出现的文字与必须禁止的虚构信息。

不要让 AI 自由编造：检测报告、认证、肉含量、功效数字、真实参数、包装清单、品牌文字和中文说明，都要以产品主档为准。AI 更适合生成场景、氛围、构图、动作和视觉证据。

# 07｜构图与镜头：别把八屏做成八页 PPT
| 构图语言 | 适合解决的问题 | 典型页面 |
|---|---|---|
| 全屏英雄图 | 一秒看懂产品与最大价值。 | 首屏、收口。 |
| 前景大产品 + 后景故事 | 让产品进入真实生活，但不丢产品主角。 | 首屏、场景、收口。 |
| 电影定格 | 放大真实痛点或人物动作。 | 痛点页、场景页。 |
| 对角线动势 | 证明气流、水流、食材、裙摆、光线等功能动感。 | 核心功能页。 |
| 超微距 + 局部放大 | 建立材质、细节、工艺和可信度。 | 细节页。 |
| S 形动作路径 | 展示连续操作，不把流程做成死板三格。 | 使用页。 |
| 档案 / 地图 / 开箱仪式 | 承载类目专属的信任问题。 | 第 7 屏。 |

# 08｜10 个行业案例库
每个案例均包含：行业与产品锚点、八屏任务表、每一屏解决的问题与可复用提示词模块、以及对应的 8 张实际生成图。阅读顺序建议：先看任务表理解销售逻辑，再看成品图理解视觉证据，最后复制提示词模块练习。

## 案例 01｜小家电：无线手持吸尘器
产品锚点：暖白磨砂机身、烟灰透明集尘杯、深灰椭圆按键、短枪柄、窄缝吸头。关键策略：把"家庭小脏乱"变成家长能立刻代入的清洁任务。
本案例的视觉逼单：孩子零食碎屑和宠物浮毛 → 吸头深入缝隙 → 结构可信 → 使用简单 → 清洁不麻烦。
| 屏 | 解决的问题 | 页面任务 / 成品方向 | 可复用提示词模块 |
|---|---|---|---|
| 01 | 这是什么？ | 家庭客厅主视觉；产品前景、妈妈和孩子宠物柔焦后景。 | 同一台暖白手持吸尘器，前景英雄角度，沙发缝隙清洁，现代家庭，顶部标题留白。 |
| 02 | 我有这个麻烦吗？ | 沙发缝碎屑、浮毛和孩子零食的电影定格痛点。 | 生活局部特写，少量碎屑与浮毛，孩子手和宠物局部入镜，产品弱化。 |
| 03 | 它怎么解决？ | 纯产品对角线动势：吸头深入缝隙，气流把灰尘导入尘杯。 | 无人物，窄缝吸头深入布艺缝隙，克制蓝灰气流与真实颗粒路径。 |
| 04 | 适合我家吗？ | 杂志式场景路线：桌面、沙发、车内、餐后碎屑。 | 一张大场景配弧形路线与小情境符号，产品在每个高频场景中出现。 |
| 05 | 为什么好用？ | 纯产品超微距：握柄、按键、透明尘杯、窄缝吸头。 | 完整产品 + 不规则局部放大镜，工业设计质感，避免规则四宫格。 |
| 06 | 操作麻烦吗？ | S 形动作路径：开机、清缝、倒灰。 | 同一场景内连续手部叠影，蓝色 S 形路径连接三次自然动作。 |
| 07 | 清洗麻烦吗？ | 清洁结构档案：尘杯、吸头、主机和清洁流程。 | 纯产品拆解悬浮，环形路径展示拆开—倒灰—清洁，不写虚假参数。 |
| 08 | 为什么选它？ | 产品前景 + 干净家庭结果；收束小脏乱解决价值。 | 产品占 60%，家庭生活柔焦后景，沿气流轨迹布置四个已证明卖点。 |

## 案例 02｜宠物食品：大包装鸡肉风味猫粮
产品锚点：虚拟品牌"脆浪"，深钴蓝、正红、亮金黄的大包装，自立袋，鸡肉食材视觉和橘白猫。关键策略：用"大包装 + 鸡肉视觉锤 + 猫的食欲反应"建立货架冲击力。
本案例的视觉逼单：猫粮缺乏吸引力 → 鸡肉风味主张 → 日常喂食场景 → 包装与颗粒细节 → 风味和保存信息。
| 屏 | 解决的问题 | 页面任务 / 成品方向 | 可复用提示词模块 |
|---|---|---|---|
| 01 | 这是什么猫粮？ | 巨大包装 + 整鸡 / 鸡腿 / 颗粒爆发式食材主视觉。 | 大容量自立袋占 60%，金黄鸡肉与颗粒环绕，猫抬头看食碗，深蓝红黄高冲击。 |
| 02 | 为什么要认真选粮？ | 猫对食碗兴趣不足，包装与鸡肉强势进入画面。 | 问题—解决方案对比，猫与食碗在左，产品和鸡肉食材锤在右。 |
| 03 | 核心吸引力是什么？ | 纯产品食材广告：包装、鸡肉、颗粒、蜂蜜般金色高光。 | 无人物，大包装英雄图，鸡肉风味意象与颗粒高速悬浮。 |
| 04 | 适合日常吗？ | 早晚开饭与收纳的杂志路线式生活图。 | 单一家庭空间中，用时间路线串联倒粮、进食、收纳。 |
| 05 | 为什么可靠？ | 纯产品微距：密封拉链、袋型、颗粒、食材插画。 | 包装斜放 + 四个不规则细节放大区，深蓝金色高光。 |
| 06 | 喂食方便吗？ | S 形手部动作：开袋、倒粮、封口。 | 同一餐桌场景内三次动作叠影，猫在中段自然靠近。 |
| 07 | 这一口是什么感觉？ | 风味地图：鸡肉、颗粒、香气与保存建议。 | 纯产品风味档案，包装居中，用食材和路径解释风味，不泛化为包装清单。 |
| 08 | 为什么最终选它？ | 大包装 + 食材爆发 + 满足进食的猫，收束日常主食价值。 | 产品 65%，猫在背景进食，四个卖点沿食材动势漂浮。 |

## 案例 03｜女装：夏季女性职业套装
产品锚点：雾灰蓝无袖西装马甲 + 高腰阔腿西裤，珍珠白内搭、银灰低跟鞋、冷灰通勤包。关键策略：用"夏日得体但不厚重"的职场矛盾，带出一套成型的通勤解决方案。
本案例的视觉逼单：天气热但不想随意 → 版型比例 → 轻薄垂感 → 多场景通勤 → 尺码与洗护确认。
| 屏 | 解决的问题 | 页面任务 / 成品方向 | 可复用提示词模块 |
|---|---|---|---|
| 01 | 适合谁穿？ | 写字楼前的全身英雄图，服装是绝对焦点。 | 同一职业女性，雾灰蓝套装，玻璃幕墙，冷感日光，通勤包，标题留白。 |
| 02 | 为什么需要它？ | 衣帽间的选择难题：厚重西装在后景，轻盈套装在手中。 | 电影定格，模特整理衣领，传统厚西装弱化，目标套装突出。 |
| 03 | 上身怎样？ | 正面、侧面、转身的连续廓形展示。 | 同一模特的连贯姿态，不切三格，突出 V 领、腰线、阔腿裤线条。 |
| 04 | 夏天穿起来如何？ | 纯产品面料页：悬挂 + 垂坠 + 微距。 | 无人物，套装大面积悬挂，冷光面料纹理，完整单品作为比例锚点。 |
| 05 | 时髦感来自哪里？ | 领型、纽扣、剪裁、裤线的超微距档案。 | 套装居中，非规则放大镜，银灰标注线，避免四宫格。 |
| 06 | 能穿去哪里？ | 城市通勤到会面的一张跨页式场景图。 | 大幅人物走在城市，右侧曲线连接写字楼、会议、咖啡会面符号。 |
| 07 | 尺码怎么判断？ | 套装档案：版型、尺码、洗护和搭配参考。 | 纯产品平铺不做普通清单；以裁缝档案式版面突出尺码选择逻辑。 |
| 08 | 为什么选它？ | 日落城市中的动态全身收口图。 | 套装在冷蓝城市中清晰突出，四个卖点沿人物步伐轨迹分布。 |

## 案例 04｜纸品：高颜值家庭装软抽纸
产品锚点：湖蓝色家庭提袋，深钴蓝与亮柠檬黄大色块，湖蓝白色独立软抽包。关键策略：将"普通日用品"做成高辨识包装，并用生活小麻烦证明随手常备价值。
本案例的视觉逼单：日常擦拭需求 → 柔软抽取感 → 家中各处可放 → 抽取与收纳简单 → 一提如何分装。
| 屏 | 解决的问题 | 页面任务 / 成品方向 | 可复用提示词模块 |
|---|---|---|---|
| 01 | 是什么好纸巾？ | 家庭装大包装 + 轻盈展开的白纸巾英雄图。 | 湖蓝包装前景占 60%，纸巾像丝带展开，家庭餐厅柔焦后景。 |
| 02 | 为什么常备？ | 餐后碎屑、桌面水渍、洗手台水珠的真实小状况。 | 电影定格的生活局部，人物只露手部，产品从边缘自然进入。 |
| 03 | 纸感怎么样？ | 纯产品蓝白对比，抽出的纸巾形成波浪。 | 无人物，深蓝背景与大面积白纸巾纹理，突出抽取口和纸感。 |
| 04 | 放在哪里？ | 餐桌到车内的弧线式家庭路线图。 | 一张大空间图配四个小场景符号，不做四格矩阵。 |
| 05 | 为什么顺手？ | 抽取口、折叠、纸感、独立包装的细节页。 | 包装居中，微距局部与亮黄标注线，日用品工业设计感。 |
| 06 | 怎么用方便？ | 抽取、擦拭、收纳的连贯手部路径。 | 单一餐桌空间，以亮黄 S 形路径连接三次动作。 |
| 07 | 一提怎么放？ | 家庭分装地图：不同区域放不同独立包。 | 纯产品家居收纳档案，产品、收纳盒与空间标签构成路线，不讲泛化包装清单。 |
| 08 | 为什么选它？ | 家庭角落常备的高颜值结果图。 | 提袋和单包在前景，孩子与妈妈柔焦后景，卖点沿纸巾曲线收束。 |

# 09｜最后的检查清单
- 每一屏是否只回答一个购买问题？
- 核心卖点是否足够早出现，且有可见证据？
- 人物页和纯产品页是否承担了不同任务？
- 相邻页面是否避免使用重复构图？
- 产品、包装、人物、Logo、颜色和结构是否全套一致？
- 中文、参数、认证、包装清单和功效是否均已人工核实？
- 第 7 屏是否回答了该品类独有的最后顾虑？
- 最后一屏是否真正收束购买理由，而不是重复首屏？

结论：AI 详情页的核心能力，不是"会写一个漂亮提示词"，而是把产品信息组织成一条完整、可信、可视化的购买决策路径。先拆疑虑，再分任务，再做证据，最后才是出图与排版。
