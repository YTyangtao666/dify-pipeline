# v3 高质量电商图 · 保姆级使用教程

> 你只需要点鼠标。全程约 5-6 分钟，产出 6 张图 + 质检报告 + 自动分支判定。

---

## 一、打开工作流（30 秒）

1. 浏览器打开：**http://127.0.0.1/apps**
2. 登录（如提示）：
   - 邮箱：`admin@dify-pipeline.local`
   - 密码：`Dify@2026admin`
3. 点击应用 **「AI高质量电商图流水线 v3」**
   （直达链接：http://127.0.0.1/app/a42cc940-cb31-4704-aed0-979e3531d5c4/workflow ）

---

## 二、跑一次生图（5 分钟）

1. 点右上角 **「运行」** 按钮
2. 填三个参数：
   - `product_id`：`P001`（保温杯）或 `P002`（榨汁杯）
   - `gen_limit`：`1`（每次跑 1 个商品）
   - `mode`：下拉选
     - `styles` = 3 种风格 × 2 张（ins明亮/场景生活感/白底主图）
     - `screens` = 8 屏视觉逼单图（痛点对比/信任背书等 8 屏结构）
3. 点 **「开始运行」**
4. 等待。可以看到每个节点亮起：
   - 前八层分析链 ≈ 1-2 分钟（DeepSeek 分析卖点）
   - 生成商品图 ≈ 3 分钟（gpt-image-2，6 张）
   - VLM质检评分 ≈ 1 分钟（gemini-3.5-flash 逐张评分）
   - 最后走分支：
     - ✅ 可用率≥80% 且 Top3打穿率≥40% → 「完成-高质量电商图」
     - ❌ 未达标 → 「Prompt优化建议」给你 3 条改进建议（DeepSeek 生成）

## 三、图片存在哪里？（重点）

所有产出都在 `~/Desktop/dify-pipeline/output/` 下：

| 内容 | 路径 | 说明 |
|---|---|---|
| **生成的图片** | `output/images/` | 文件名规则：`商品ID_风格名_序号.png`，如 `P001_电商主图白底_1.png` |
| **质检报告** | `output/eval/eval_report.json` | 每张图的分数/问题/Top3打穿判定 |
| 浏览报告（更方便） | 浏览器开 `http://127.0.0.1:8100/report` | 直接看 JSON，不用开文件 |

**最快的看法**：Finder → 前往文件夹（⌘⇧G）→ 粘贴：
```
~/Desktop/dify-pipeline/output/images
```
按「修改日期」排序，最新的就是刚生成的。图片可直接拖进微信/详情页使用。

**报告怎么读**：
- `usable_rate` = 可用率（≥80 达标）
- `top3_coverage` = Top3 卖点打穿率（越高越好，说明卖点真的画进图里了）
- `items` 里每张图的 `score`（0-100）、`issues`（问题列表）、`top3_hits`（每条卖点是否视觉可见）

## 五、常见问题

| 症状 | 原因 | 处理 |
|---|---|---|
| 「生成商品图」节点红色 | 生图 API 失败（余额/网络） | 看节点详情里的报错；curl 测 `https://api.apimart.ai` 余额 |
| 运行按钮卡住不动 | analyze 环节 DeepSeek 慢 | 正常，最长等 2 分钟；日志里能看到节点状态 |
| 图片想重跑 | 旧图会被同名覆盖 | 直接再跑一次即可；想保留旧图先把 images 里感兴趣的改名 |
| 想换商品 | data/products.json 里加商品 | 告诉我，我帮你加 |
| 每天自动跑 | launchd 每天 9 点触发 | 已配好，无需操作（详见 docs/DEPLOY_NOTE.md） |
