# 模特三视图锚定设计（Model Anchor v2）

## 问题

两段式（商品标准特写先行）已解决商品一致性：gpt-5.2-pro 复核 7/7 印花文字一致、
无多余图案、颜色仅轻微色差。**衣服颜色问题已解决（用户确认 2026-08-17）**。

剩余缺陷：模特不一致——5 张模特图人种/发型漂移（黑长卷亚洲脸、棕发丸子头、金发马尾欧美脸），
两个识图模型（gemini-2.5-flash / gpt-5.2-pro）交叉指认一致。

根因：model_1.png 只是普通参考图之一，没有「人物设定」环节，每张图独立理解人物。

## 设计：双锚定（商品锚 + 模特锚）

对齐电商行业 character-sheet 工作流：

```
素材: flat_1.png(平铺) + model_1.png(模特原图)
  │
  ├─ Stage 0A: 商品标准特写  {pid}_00A_商品标准特写.png   [已有]
  │    参考=flat_1, 白底, 最强商品复刻约束
  │
  ├─ Stage 0B: 模特三视图    {pid}_00B_模特三视图.png     [新增]
  │    参考=[model_1, flat_1, 00A]
  │    正/侧/背三视图并排, 模特**穿着该商品**, 纯白背景
  │    约束: 面部/发型/肤色/身材与 model_1 100% 一致
  │         服装与平铺图逐项复刻（双重锁: 人+货绑定成像）
  │    生成后 VLM QC: 人像匹配 model_1 && 商品匹配 flat_1, 不达标重试≤2 次
  │
  └─ Stage 1..N: 槽位生成
       模特槽位(uses含model): 参考图 = [00A商品锚, 00B模特锚]   ← 恰好2张,角色明确
       商品槽位(无model):     参考图 = [00A商品锚, flat_1]
       prompt 指令按位置声明:
         "第一张参考图是商品标准图——服装逐项复刻"
         "第二张参考图是模特三视图——面部/发型/身材100%一致,严禁换人换人种"
```

### 关键决策

1. **三视图穿商品**而非素色：单图同时锁「人+货」绑定关系，下游不再需要理解
   「哪张参考管脸、哪张管衣服」的交叉对应；风险（三视图商品出错会传染）由 QC 门拦截。
2. **参考图恰好两张、按位置声明**：告别「按内容识别」的模糊表述（此前 3 张参考图
   时锚定句指位漂移过一次），每个位置职责唯一。
3. **失败降级**：00B 生成/QC 失败不阻塞槽位——回退现行为（00A + flat + model 原图）。
4. **锚定句双写同步**：fashion.py 常量 + 技能包 JSON 已烙 template 同步刷新
   （历史坑：只改代码不刷 JSON 无效）。

## 影响

- 模特一致性：期望从「明显不同人」→「同一人」（gpt-5.2-pro 终审）
- 成本：+1 张三视图生成 + QC 调用（约 +40s/商品）
- 兼容：无 model 素材的商品自动跳过 0B，行为不变
